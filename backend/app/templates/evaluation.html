Evaluation

Does associative or iterative recall actually beat conventional retrieval?

Four retrieval strategies, run read-only against one shared corpus of stored memories with one shared query set, so the question has an answer with numbers behind it — including the answer “no”. Read the trade-offs rather than a ranking: a strategy buys recall with false retrieval and latency, and this page deliberately computes no single score that would hide that.
